# 流程图布局

## 形状词汇

| 形状 | 含义 | SVG 元素 |
|------|------|---------|
| 圆角矩形（大圆角） | 开始/结束 | `<rect rx="25">` |
| 矩形 | 处理/动作 | `<rect rx="6">` |
| 菱形 | 决策 | 旋转 45° 的 `<polygon>` |
| 平行四边形 | 输入/输出 | 带倾斜的 `<polygon>` |
| 圆柱 | 数据存储 | 椭圆 + 矩形组合 |

## 流向

主流程：**从上到下**。分支从决策处向左/右延伸。

## 布局算法

1. **识别主路径**（happy path / 最常见流程）——它沿中心竖直向下
2. **从决策分支：** "Yes" 沿中心继续向下，"No" 向右分支（空间紧张时向左）
3. **合并路径：** 用 L 形连接把分支导回主路径
4. **回环：** 沿图最左/最右侧用弧形路径向上布线

## 间距

- 步骤间垂直间距：60-80px（足够放箭头 + 可选标签）
- 决策菱形高度：70px（点到点）
- 决策菱形宽度：100px（点到点）
- 分支水平偏移：距中心 200px
- 合并连接器净空：距任意方框 20px

## 决策标签

将 "Yes" / "No"（或 "True" / "False"、"是" / "否"）标签直接放在出口箭头上，距菱形边缘 10px：

```svg
<!-- 中心 (400, 200) 处的决策菱形 -->
<!-- Yes: 向下 -->
<line x1="400" y1="235" x2="400" y2="300" stroke="#64748b" marker-end="url(#arrow)"/>
<text x="412" y="260" fill="#34d399" font-size="8">Yes</text>

<!-- No: 向右 -->
<line x1="450" y1="200" x2="550" y2="200" stroke="#64748b" marker-end="url(#arrow)"/>
<text x="480" y="193" fill="#fb7185" font-size="8">No</text>
```

## 配色策略

- **起止节点：** Highlight 色（蓝）
- **处理步骤：** Primary（青）或 Secondary（翠绿）
- **决策菱形：** Accent（琥珀）——天然吸引视线
- **错误/异常路径：** Alert（玫红）虚线箭头
- **主路径箭头：** 比分支箭头略亮（用 `stroke-opacity` 区分）

## 复杂流程图

对 10 步以上的流程图：
- 将相关步骤归入泳道（带标题条的纵向列）
- 在每个泳道顶部加一行"阶段"标题
- 泳道使用架构图中的区域边界样式
